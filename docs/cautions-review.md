# 주의사항 표 검토 문서

> PLAN 작업 4용이에요. `node scripts/make-review-sheet.mjs`로 `data/cautions.ts`에서 자동으로 만들어요.
> 검토 순서: 농지 → 건물(주거·비주거) → 차량 → 기계 → 나머지 (PLAN 질문 2-나)
> 조사 표시: ✔ 검색으로 확인 · △ 일부만 확인/2차 자료 · ✖ 공식 근거 못 찾음 (법령 원문은 직접 열어보지 못했어요)

**검토 방법:** 항목마다 출처 링크를 열어 원문과 맞는지 보고, 아래 칸에 ✅(맞음) / ✏️(고칠 점 적기) / ❌(빼기)를 적어 주세요.
검토가 끝난 항목은 `status`를 `confirmed`로, `checkedAt`을 검토한 날로 바꿔요.
